# 个人培养增强版

此发行版供 Windows x64 国服使用，程序和资源从 `rsdadada/MaaAssistantArknights` 的个人 Releases 更新。

## 首次使用

将完整包解压到独立目录。需要继承设置时，关闭 MAA 后复制旧目录的 `config` 和 `data`；资源缓存由新版本重新建立。运行 `MAA.exe`，在培养页设置干员的精英阶段、等级、技能和专精目标，开启自动补料，并将培养任务移到普通刷图和库存保持之前。

按列表顺序优先培养。当天无法刷的关卡、忙碌的训练室和不足的理智会使该目标暂缓，下一次重新识别并继续。原库存保持目标不会被改写。

信用、红票和理智药默认关闭、额度为零。开启后设置每日上限和保留余额；红票只兑换芯片助剂，临期药选项只使用两天内到期的药。源石恢复始终关闭。额度按档案和国服游戏日保存，重启不能获得第二份额度。总经验的关卡覆盖使用 `__experience`。

## 更新与故障

首次运行个人版会启用公测渠道和自动下载安装，之后保留你的偏好。公测渠道也接收正式版。程序包必须与个人发行清单匹配；资源只安装到兼容的程序构建，官方旧资源缓存不会参与加载。

未专门进行实机培养测试。新流程通过构建、配置、补料规划和离线检查，实际游戏效果随日常使用验证。识别不确定时会停止相应动作，并在任务日志记录原因。

## 维护

定时入口是 `.github/workflows/personal-release.yml`，每六小时检查一次，也可在 Actions 手动运行。配置位于 `personal/release-config.json`，补丁顺序位于 `personal/patches/series`。自动发布由仓库变量 `PERSONAL_PUBLISH_ENABLED=true` 控制；关闭后仍构建并保留可下载产物。

修改增强代码后，先运行测试，再按当前 `patchBase` 导出 Git 格式补丁并更新 series。已发布版本需要递增 `revision`。不要重写已公开的 tag。工作流会从官方发行 tag 重放补丁，冲突或验证失败时不发布；失败的未公开发行会从原 tag 恢复固定源码继续构建。

培养预算文件位于 `data/personal-cultivation/<profile_id>.jsonl`，保留它以防重置额度。请结合 `debug/asst.log`、`debug/gui.log` 和失败的 Actions 日志定位问题。
