# 個人用育成拡張版

Windows x64・中国版クライアント向けです。プログラムとリソースは `rsdadada/MaaAssistantArknights` の個人 Releases から更新します。

## 初回起動

完全パッケージを別のフォルダーに展開します。設定を引き継ぐ場合は MAA を終了し、以前の `config` と `data` をコピーしてください。リソースキャッシュは新しく作成します。`MAA.exe` を起動し、昇進・レベル・スキル・特化の目標を設定して素材補充を有効にし、育成を通常周回と在庫維持の前へ移動します。

リスト順に育成し、未開放ステージ、訓練室の使用中、理性不足は次回へ持ち越します。在庫維持の設定は変更しません。信用・購買資格証・理性回復剤は初期状態で無効、上限はゼロです。有効にする前に日次上限と残高の保留下限を設定してください。購買資格証は SoC 強化剤のみ、期限限定の回復剤設定は二日以内に期限を迎えるもののみを使用します。純正源石は使用しません。上限はプロファイルと中国版の日付区切りで保存され、再起動でも維持されます。総経験値の周回先キーは `__experience` です。

## 更新と障害

初回はベータチャンネルと自動ダウンロード・インストールを有効にし、その後は設定を保持します。ベータでも正式版を受け取ります。パッケージは個人版のメタデータと一致する必要があり、リソースは対応するビルド専用です。以前の公式キャッシュは読み込みません。

専用の実機育成テストは行っていません。ビルド、設定、素材計画、オフライン検証を行い、ゲーム内の動作は日常利用で確認します。認識が不確かな場合は該当操作を停止し、理由をログに残します。

## 保守

`.github/workflows/personal-release.yml` は六時間ごとに確認し、手動実行にも対応します。設定は `personal/release-config.json`、パッチ順序は `personal/patches/series` です。リポジトリ変数 `PERSONAL_PUBLISH_ENABLED=true` で公開します。無効でもビルド成果物は取得できます。

変更後はテストし、`patchBase` から Git 形式のパッチを出力して series を更新します。公開済みの基準バージョンでは `revision` を増やし、公開タグを書き換えないでください。競合や検証失敗では公開せず、未公開の失敗は元のタグから再開します。

日次記録 `data/personal-cultivation/<profile_id>.jsonl` を保持してください。`debug/asst.log`、`debug/gui.log` と Actions ログで障害を調査します。
