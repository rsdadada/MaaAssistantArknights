# 개인 육성 확장판

Windows x64와 중국 서버 클라이언트를 대상으로 합니다. 프로그램과 리소스는 `rsdadada/MaaAssistantArknights`의 개인 Releases에서 업데이트합니다.

## 처음 실행

전체 패키지를 별도 폴더에 압축 해제합니다. 설정을 가져오려면 MAA를 종료한 뒤 기존 `config`와 `data`를 복사하고 리소스 캐시는 새로 생성하도록 둡니다. `MAA.exe`에서 정예화, 레벨, 스킬, 특화 목표를 설정하고 재료 보충을 활성화한 뒤 일반 파밍과 재고 유지보다 앞에 육성을 배치합니다.

목록 순서대로 진행하며 닫힌 스테이지, 사용 중인 훈련실, 이성 부족은 다음 실행으로 넘깁니다. 기존 재고 유지 목표는 바꾸지 않습니다. 크레딧, 구매 증명서, 이성 회복제는 기본적으로 비활성화되고 한도는 0입니다. 활성화 전에 일일 한도와 남겨 둘 잔액을 설정합니다. 구매 증명서는 칩 첨가제에만 사용하며 임박 옵션은 이틀 이내 만료되는 회복제만 사용합니다. 오리지늄 회복은 사용하지 않습니다. 한도는 프로필 및 중국 서버의 게임 날짜를 기준으로 저장되어 재시작해도 유지됩니다. 총 경험치 파밍 경로 키는 `__experience`입니다.

## 업데이트와 오류

최초 개인판 실행 시 베타 채널과 자동 다운로드·설치를 활성화하고 이후에는 선택을 유지합니다. 베타 채널도 정식 버전을 받습니다. 패키지는 개인 릴리스 정보와 일치해야 하며 리소스는 호환되는 프로그램 빌드에만 적용합니다. 기존 공식 리소스 캐시는 읽지 않습니다.

별도의 실제 게임 육성 테스트는 수행하지 않았습니다. 빌드, 설정, 재료 계획, 오프라인 검사를 수행하고 실제 동작은 일상 사용 중 확인합니다. 인식이 불확실하면 해당 동작을 멈추고 이유를 기록합니다.

## 유지 관리

`.github/workflows/personal-release.yml`은 6시간마다 확인하며 수동 실행도 지원합니다. 설정은 `personal/release-config.json`, 패치 순서는 `personal/patches/series`입니다. 저장소 변수 `PERSONAL_PUBLISH_ENABLED=true`가 자동 게시를 활성화합니다. 꺼져 있어도 빌드 결과물을 다운로드할 수 있습니다.

수정 후 테스트하고 `patchBase` 기준의 Git 형식 패치를 내보내 series를 갱신합니다. 이미 게시된 기준 버전은 `revision`을 올려야 하며 공개 태그를 덮어쓰지 않습니다. 충돌이나 검증 실패 시 게시하지 않고, 미공개 실패 릴리스는 원래 소스 태그에서 다시 진행합니다.

일일 사용 기록 `data/personal-cultivation/<profile_id>.jsonl`을 보관합니다. 문제는 `debug/asst.log`, `debug/gui.log`, Actions 로그로 확인합니다.
